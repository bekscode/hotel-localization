# Hotel Localization
### Introduction
This application was built as a final project for the Western Governors University Advanced Java course. For this assessment I modified a Spring application with a Java back end and Angular front end to include multithreaded language translation, a message at different time zones, and currency exchange. Then, built a Docker image of the app and explained how to deploy the application to Azure or AWS cloud services.

## Installation
Open with IntelliJ or your chosen IDE with the required libraries.
